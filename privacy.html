Липли — политика конфиденциальности

Политика конфиденциальности игры «Липли» Дата вступления в силу: 2026-11-07 Ответственное лицо: Евгений Публичное имя разработчика: Jeantik Страна: Российская Федерация Поддержка: lipli.team@gmail.com

Игра на устройстве

«Липли» — офлайн-игра. В ней нет регистрации, рекламы, аналитики, покупок, сервера игры и автоматической отправки данных разработчику. Приложение не запрашивает разрешение на доступ к интернету.

Локальные данные

На вашем устройстве сохраняются введённые имена/псевдонимы игроков, цвета, параметры партии, поле, счёт, очередь, кубики, черновик хода и настройки. Для работы игры не требуется настоящее имя. Данные нужны для продолжения партии и сохранения выбранных настроек. Резервные копии прежних локальных файлов могут сохраняться при замене или восстановлении партии. Удаление данных приложения в настройках Android удаляет и эти копии.

Перенос сохранения

Только по вашему действию игра может записать партию и настройки в выбранный файл или прочитать выбранный вами файл. Экспорт содержит имена игроков и не шифруется игрой. Вы выбираете место хранения; облачный провайдер в системном окне может передать файл своему сервису. Игра не отправляет файл разработчику. Удалите экспортированные файлы отдельно, когда они больше не нужны. Автоматическое резервное копирование и перенос данных средствами Android отключены настройками приложения; поведение изменённой системы производителя может отличаться.

Разрешения и диагностика

Разрешение VIBRATE используется для отключаемого тактильного отклика. Камера, микрофон, местоположение, контакты, рекламный идентификатор и доступ ко всему хранилищу игре не нужны. Системное окно предоставляет доступ только к выбранному документу. Локальные диагностические сообщения движка могут содержать сведения о версии системы, параметрах экрана и технических ошибках; автоматического отправления этих сообщений разработчику нет. Android и магазин могут обрабатывать собственную диагностику по своим настройкам и правилам.

Обращения в поддержку

Нажатие на адрес поддержки открывает отдельное почтовое приложение. Письмо отправляется только по вашему решению в нём. Получатель увидит ваш адрес, содержание письма и приложенные вами материалы. Не отправляйте пароли, ключи подписи и ненужные персональные сведения. Письма используются для ответа и разбора обращения; почтовый сервис может обрабатывать их по своим условиям. Переписка и вложения удаляются не позднее 12 месяцев после закрытия обращения. Запросы об удалении принимаются на lipli.team@gmail.com.

Удаление и управление

Игровые данные можно удалить через Android → Приложения → Липли → Хранилище → Очистить данные, либо удалив приложение. Экспортированные документы и письма при этом не удаляются. По вопросам обработки/удаления переписки напишите на lipli.team@gmail.com. В игре нет учётной записи, поэтому удаление аккаунта не требуется.

Изменения

При изменении обработки данных владелец обновит эту политику и её дату. Доступная без сети копия включается в соответствующую версию игры.

Публичные справочные страницы

В коде страниц нет аналитики, cookies, внешних шрифтов и форм отправки данных. Провайдер хостинга: GitHub Pages (GitHub, Inc.). GitHub сохраняет IP-адреса посетителей GitHub Pages для обеспечения безопасности, в том числе при посещении без входа в GitHub. Запрос также содержит технические сведения, передаваемые браузером. Обработка и сроки хранения у GitHub регулируются его политикой конфиденциальности; разработчик не устанавливает их и не обещает их удаление в срок хранения писем поддержки. Политика GitHub: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement Сведения о журналировании GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection
