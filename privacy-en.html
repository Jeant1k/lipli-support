Lipli — privacy policy

Privacy policy for Lipli Effective date: 2026-11-07 Responsible contact: Eugene Public developer name: Jeantik Country: Russian Federation Support: lipli.team@gmail.com

On-device game

Lipli is an offline game. It has no accounts, advertisements, analytics, purchases, game server or automatic data transmission to the developer. The app does not request internet permission.

Local information

Player names/nicknames, colours, match settings, board, scores, turns, dice, draft placements and preferences are stored on your device to continue play and remember settings. Real names are not required. Older local copies may remain when replacing or recovering a match. Clearing app storage in Android also removes those copies.

Save transfer

Only at your request, the game can export a match and preferences to a file, or read a document you select. The export contains player names and is not encrypted by the game. You choose its location; a cloud provider selected in the system picker may upload it to its service. The game does not send it to the developer. Delete exported files separately when no longer needed. App settings disable automatic Android backup and device transfer; modified vendor systems may behave differently.

Permissions and diagnostics

VIBRATE provides optional haptic feedback. The game does not need camera, microphone, location, contacts, advertising ID or access to all storage. The system picker grants access to the selected document. Local engine diagnostics may include OS version, display parameters and technical errors; the game does not automatically send these logs to the developer. Android and the store may process their own diagnostics under their settings and policies.

Support

Tapping the support address opens a separate email app. You decide whether to send a message there. The recipient receives your email address, message and any attachments you choose. Do not send passwords, signing keys or unnecessary personal information. Messages are used to answer and investigate the request; the email provider may process them under its terms. Support correspondence and attachments are deleted no later than 12 months after the request is closed. Send deletion requests to lipli.team@gmail.com.

Deletion and control

Clear storage via Android → Apps → Lipli → Storage → Clear data, or uninstall the app, to remove internal game data. Exported documents and emails are not removed this way. For support correspondence or deletion requests, contact lipli.team@gmail.com. There is no in-game account to delete.

Changes

The owner will update this policy and its effective date if data handling changes. An offline copy is included with the corresponding game version.

Public support pages

The page code contains no analytics, cookies, external fonts or data-submission forms. Hosting provider: GitHub Pages (GitHub, Inc.). GitHub logs and stores visitors' IP addresses for security purposes, including visits without signing in. Requests also contain technical information sent by the browser. GitHub's privacy statement governs its processing and retention; the developer does not set these periods or promise that hosting logs are deleted within the support-email retention period.
