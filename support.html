Поддержка Липли / Lipli support

По вопросам об игре пишите на lipli.team@gmail.com. For questions about the game, email lipli.team@gmail.com.

Для сообщения об ошибке укажите версию игры, модель телефона, версию Android и действия перед проблемой. Снимок экрана необязателен: перед отправкой уберите личные сведения. Не присылайте ключи, пароли или файлы сохранений без необходимости.

For a bug report, include game version, device model, Android version and steps to reproduce. Screenshots are optional; remove personal details before sending. Do not send keys, passwords or save files unless necessary.

Удаление игровых данных: настройки Android → Приложения → Липли → Хранилище → Очистить данные. Экспорты удаляются отдельно. Delete local game data via Android app storage settings. Exported files must be deleted separately.
